# Zero-Day-Intrusion-Detection-System-using-Graph-Neural-Networks-GNN-and-Explainable-AI
Developed a Zero-Day Intrusion Detection System using Graph Neural Networks (GNN) and Explainable AI to detect unknown cyberattacks. Built and evaluated the model on network traffic datasets using PyTorch Geometric, improving detection accuracy while providing interpretable predictions through GNNExplainer.
